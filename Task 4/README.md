# E-Commerce Sales Data Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data to understand business performance, customer behavior, and regional trends. The goal is to provide actionable insights that can help improve decision-making, increase sales, and boost profitability.

The analysis was performed using **SQL** for data cleaning and querying, and **Power BI** for creating interactive dashboards and visualizations.

---

## 🎯 Business Objectives

- Analyze overall sales performance
- Understand customer spending behavior
- Identify regional sales trends
- Evaluate product category performance
- Test the impact of discounts on sales

---

## 📁 Dataset Information

The dataset contains transactional data from an e-commerce platform, including:

- **Order ID**, **Order Date**
- **Product Name**, **Category**, **Sub-Category**
- **Customer Name**, **Region**, **Country**, **State**
- **Quantity**, **Sales**, **Profit**, **Discount**
- **Customer Segment**

> Total Records: 3,492 transactions

---

## 🧹 Data Cleaning Steps

1. **Data Type Conversion** – Converted dates and numerical fields to proper formats.
2. **Missing Values Check** – No missing values found.
3. **Duplicate Removal** – Removed duplicate order entries.
4. **Future Date Check** – No future dates present.
5. **Negative Value Check** – No negative sales, profit, or quantity.
6. **Text Standardization** – Standardized names and categories (capitalization, trimming).

## 🧪 Hypothesis Testing

**Question:** Do discounts increase product sales?

- **Null Hypothesis (H₀):** Discount does not affect sales.
- **Alternative Hypothesis (H₁):** Discount increases sales.

**Method:** Correlation analysis between discount and sales.

**Result:** A **positive correlation** was found — higher discounts are associated with higher sales.

✅ **Conclusion:** Discounts can help boost product sales.
