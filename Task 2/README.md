# 📊 Superstore EDA Project

## 📌 Project Overview
This project is about **Exploratory Data Analysis (EDA)** on the Superstore dataset.  
The main goal is to understand the data, clean it, and find useful business insights.

---

## 📁 Dataset Information
- Dataset Name: Superstore Sales Data  
- Total Rows: 9,994  
- Total Columns: 21  

The dataset contains:
- Customer details  
- Order details  
- Product categories  
- Sales, Profit, Discount  

---

## 🎯 Project Objective
- Clean the dataset  
- Understand data structure  
- Find patterns and trends  
- Get business insights  

---

## 🛠️ Tools Used
- SQL (PostgreSQL)  
- Excel / CSV  
- Power BI (for visualization)  

---

## 🔄 Data Cleaning Steps
- Converted data types (text → numeric, date)  
- Checked missing values (No missing data found)  
- Checked duplicate records (No duplicates found)  
- Removed extra spaces and cleaned text  
- Verified logical errors (date, negative values)  

---

## 📊 Analysis Performed
- Univariate Analysis (single column)  
- Bivariate Analysis (two columns)  
- Correlation Analysis  
- Category-wise analysis  
- Region-wise performance  
- Year-wise sales trend  

---

## 🔍 Key Insights
- 📉 High discount reduces profit  
- 💻 Technology category gives highest profit  
- 📦 Office Supplies has highest number of orders  
- 👥 Consumer segment has most customers  
- 🌍 West and East regions have highest sales  
- 🚚 Same Day shipping gives high-value orders  

---

## 📈 Business Recommendations
- Reduce high discounts  
- Focus more on Technology products  
- Improve low-profit categories  
- Target high-value customers  

---

## 📂 Project Files
- `Superstore.sql` → SQL queries for cleaning and analysis  
- `Superstore_clean.csv` → Cleaned dataset  
- `EDA Report.pdf` → Full analysis report  
- `Power BI File (.pbix)` → Dashboard  

---

## ✅ Conclusion
The dataset is clean and ready for analysis.  
This project helps in understanding business performance and making better decisions.
